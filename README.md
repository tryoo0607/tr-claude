# tr-claude

Claude Code용 개발 워크플로 plugin 배포 저장소다. 내용은
[`tr-kit-source`](https://github.com/tryoo0607/tr-kit-source)에서 생성하며 직접 수정하지 않는다.

## 설치

Claude Code에서 marketplace `tryoo0607/tr-claude`를 추가한 뒤 `tr-claude` plugin을 설치한다.

개인 저장소 연결이나 개인 전용 skill은 이 공개 plugin에 포함되지 않는다.
